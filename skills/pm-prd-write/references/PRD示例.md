### 0.2 一页结论

- 一句话方案：在圈子活动详情页报名区，根据用户身份提前展示优先报名资格，减少无效报名尝试和资格咨询。
- 已确认目标与方案：让用户点击前理解当前是否可报名；复用服务端现有资格判定，不改变报名资格规则。
- 关键取舍与非目标：本期不改活动列表、规则正文和名额分配机制。
- 本次交付范围与版本：iOS、Android 详情页、资格展示状态、相关埋点和 FAQ，随 v3.8.0 发布。
- 效果判断标准：资格限制返回率和资格咨询量下降，符合资格用户报名转化不明显受损。
- 用户主路径与页面影响：入口 → 活动详情 → 查看资格 → 报名 / 等待；本次只改活动详情页。
- 关键信息结构变化：在报名区域附近新增资格说明，活动最终状态仍优先展示。
- 最大风险：详情展示状态与用户点击时的实时资格可能不一致。

### 1.2 已确认方向、范围与取舍

- 已确认方向：在详情页报名区展示个体化资格状态，并复用服务端现有身份与活动阶段判断。
- 选择依据：距离决策动作最近、可解释个人资格、无需改变资格规则。
- 上游未选方向：规则正文统一提示无法匹配个人身份；列表全链路提示投入较高且缺少入口侧证据。
- 一级范围：活动详情页报名链路、登录用户、圈内优先期和公开报名阶段。
- 非目标：不改变资格、名额、排序、通知和活动创建规则。
- 重大约束：页面提示不能代替报名接口实时校验；旧客户端必须继续可报名。

### 2.1 方案闭环与目标流程

页面加载时取得活动阶段、用户身份和报名状态，生成资格展示状态；用户阅读提示后决定等待或报名；点击报名时服务端再次实时校验。

| SCN-02 | 点击报名 | 用户 / 服务端 | 实时活动与身份 | 提交报名 | 成功或资格限制 | 以实时结果为准 |

### 3.3 功能需求明细

#### FR-01 返回资格展示状态

- 所属页面 / 信息结构：PAGE-01 / IA-01、IA-02。
- 使用角色与场景：登录用户进入开启圈内优先报名的活动详情页。
- 前置条件与触发：页面请求详情信息。
- 系统处理：服务端根据活动状态、报名阶段、成员身份和报名状态返回展示状态。
- 状态枚举：`member_available`、`non_member_waiting`、`normal_registration`、`closed`。
- 异常兜底：无法获得身份时不返回肯定性资格；点击报名仍实时校验。
- 原型 / 设计：UI-03；关联规则：RULE-01；对应验收：AC-01、AC-02、AC-03。

#### FR-02 展示差异化资格提示

| 展示状态 | 页面表现 | 按钮 | 补充信息 |
|---|---|---|---|
| `member_available` | 当前为圈内优先报名阶段，你可优先报名 | 可报名 | 无 |
| `non_member_waiting` | 公开报名后你可参与 | 不可报名 | 有开放时间时展示具体时间 |
| `normal_registration` | 不展示优先提示 | 按原逻辑 | 无 |
| `closed` | 只展示最终状态 | 不可报名 | 按原逻辑 |

- 资格提示仅用于解释，不代替服务端校验。
- 开放时间缺失时使用不含具体时间的兜底文案。
- 已取消、结束或截止状态优先于资格提示。
- 原型 / 设计：UI-01、UI-02；关联规则：RULE-01；对应验收：AC-01 至 AC-04。

#### FR-03 埋点

- `priority_eligibility_hint_view`：提示曝光，包含展示状态、活动类型和用户身份。
- `activity_signup_click`：沿用事件，新增展示状态。
- `activity_signup_result`：沿用事件，校验失败原因参数。
- 对应指标：MET-01、MET-02；对应验收：AC-05。

### 6.2 研发验收标准

#### AC-01 圈内成员优先报名

- Given：活动处于圈内优先期，用户为圈内成员。
- When：用户进入详情页。
- Then：按 UI-01 展示可优先报名提示，按钮可用，点击后沿用实时报名流程。

#### AC-02 圈外用户等待开放

- Given：活动处于圈内优先期，用户不是圈内成员。
- When：用户进入详情页。
- Then：按 UI-02 展示等待开放提示，按钮不可用；有开放时间时展示时间。

#### AC-03 实时结果优先

- Given：页面已展示资格，但身份或活动阶段随后变化。
- When：用户点击报名。
- Then：以服务端实时结果为准，并展示对应成功或失败反馈。

#### AC-04 最终状态与旧逻辑回归

- Given：活动已结束、取消、截止，或不是圈子活动。
- When：用户进入详情页。
- Then：最终状态优先；不适用场景与改动前一致。

#### AC-05 埋点完整

- Given：用户看到提示并点击报名。
- When：曝光、点击和结果事件上报。
- Then：事件包含活动、身份、展示状态和结果字段，测试环境可核对。
